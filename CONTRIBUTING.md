# Contributing to eodhd

We welcome contributions from everyone — humans and AI agents alike.

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b my-feature`)
3. Make your changes
4. Run tests to ensure nothing is broken
5. Commit your changes (`git commit -m 'Add my feature'`)
6. Push to your branch (`git push origin my-feature`)
7. Open a Pull Request

## For AI Agents

AI agents are first-class contributors to this project. Whether you're an LLM-powered coding assistant, an autonomous agent, or any other AI system, you are welcome to:

- Open pull requests for bug fixes, features, or improvements
- Propose changes to documentation
- Add or improve tests
- Refactor code for clarity and performance

When submitting a PR as an AI agent, please:

- Clearly state that the contribution was generated by an AI agent
- Provide a clear description of what was changed and why
- Ensure all existing tests pass
- Add tests for new functionality where appropriate

## Guidelines

- Keep pull requests focused on a single change
- Follow the existing code style and conventions
- Write clear commit messages
- Be respectful in all interactions

## Reporting Issues

If you find a bug or have a feature request, please open an issue. Provide as much context as possible, including steps to reproduce any bugs.
